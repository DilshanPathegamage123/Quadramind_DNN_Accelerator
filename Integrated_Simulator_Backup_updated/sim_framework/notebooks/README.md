## `scheduler_ranking_colab.ipynb`

Charts for the scheduler-chooser results — which of the 14 policies wins, on
which workload mix, under which optimisation objective.

**Self-contained.** The 15 CSVs it plots (13 × `ranked_*.csv`,
`objective_matrix.csv`, `objective_recommendation.csv`) are embedded in the
notebook as a base64 zip, so it runs in Google Colab with no upload, no
`pip install`, and no access to the RTL, Verilator or Vivado. Only pandas,
numpy and matplotlib are used — all preinstalled in Colab.

### Open it in Colab

- **From Drive** — upload the `.ipynb` to Google Drive, right-click →
  *Open with* → *Google Colaboratory*, then *Runtime → Run all*.
- **From your machine** — [colab.research.google.com](https://colab.research.google.com)
  → *File → Upload notebook*.

### Plotting fresh results

Re-run the chooser, then point the notebook at the new CSVs instead of the
embedded copy by setting `DATA_DIR` in cell 0:

```bash
PYTHONPATH=. python scripts/choose_scheduler.py --mix mix3 --goal turnaround_us
PYTHONPATH=. python scripts/sched_objective_matrix.py
```

```python
DATA_DIR = "/content/drive/MyDrive/sched_chooser"   # or any folder of ranked_*.csv
```

The loader keys scenarios off the filename (`ranked_<workload>_<goal>.csv`),
so new mixes and goals appear in every chart with no code change.

### What each figure shows

| Section | Figure | Reads |
|---|---|---|
| 2 | ranking bars | one `ranked_*.csv` — all 14 policies, best at top, excluded policy greyed not dropped |
| 3 | objective small-multiples | the same workload re-ranked under every objective it was scored on |
| 4 | rank-stability heatmap | rank of each policy across workloads at a fixed objective |
| 5 | winner grid | `objective_matrix.csv` — winner + value per objective × mix |
| 6 | latency-vs-area Pareto | `mean_turnaround_us` against measured LUTs |
| 7 | recommendation table | `objective_recommendation.csv` |
| 9 | export | every figure as PNG + PDF, zipped for download |

Timing columns combine **model** cycle counts with **measured** post-synthesis
Fmax (Vivado 2025.2 OOC). `BATCHDNN_PP` has no current synthesis result and is
carried as *excluded* — see the note column in
`results/sched_chooser/ranked_Workload_mix_3_turnaround_us.csv`.
